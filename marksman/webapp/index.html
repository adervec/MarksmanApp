Not working? Use your own Google client

Google only allows sign-in from web addresses registered against a client ID. This app reuses the one from Tachyread, which is registered for adervec.github.io and a couple of local ports. If your address isn't one of them, create an OAuth client ID (type: Web application) in the Google Cloud console, add this page's address under Authorized JavaScript origins, and paste the ID here.
