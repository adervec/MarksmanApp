# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][cc] as its code of
conduct.

Short version: be respectful, assume good faith, and keep discussion about the
code. Harassment, personal attacks, and unwelcome attention are not acceptable
here, in issues, pull requests, or anywhere else the project is discussed.

**Reporting.** Contact the maintainer, [@adervec](https://github.com/adervec),
privately through GitHub. Reports are handled confidentially. The maintainer
may edit, hide, or delete contributions that break these rules, and may block
repeat offenders from the project.

This is a small hobby project with one maintainer — there is no committee and
no formal SLA, but reports are taken seriously.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
